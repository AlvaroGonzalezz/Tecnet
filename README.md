# Tecnet
Sistema de Gestión y Control Escolar

Equipo:
- Alvaro Sánchez González
- Luis Diego Barajas Escobar
- Emmanuel Obregon Estrada

Funciones / Requerimientos

- Administrar docentes, asignaturas, grupos y cargas académicas.
- Controlar calificaciones y reportes académicos.
- Optimizar procesos administrativos y académicos.
- Registro de nuevo ingreso (datos personales, documentos, fotografía).
- Asignación de grupo y carga académica.
- Historial académico completo.
- Control de estatus (ejemplo activo, baja temporal, egresado).
- Registro de asignaturas para su asignación a estudiantes.
- Registro de calificaciones por parcial y final.
- Cálculo automático de promedios.
- Generación de boletas y kardex académico.
- Emisión de ficha académica y recibos para que pague el alumno.
- Gestión de roles, que son: Administrador, director, Docente, Administrativo, Alumno.
- Autenticación con usuario y contraseña.
